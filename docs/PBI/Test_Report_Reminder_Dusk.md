# Laporan Uji — Login & Reminder (PBI 32–34, Laravel Dusk)

**Proyek:** PPL-C-SIBIMA  
**Format:** satu baris = satu langkah (Steps bernomor 1, 2, 3 …). Kolom **PBI ID** / **Case ID** boleh dikosongkan pada baris lanjutan jika sama dengan baris di atasnya (sesuai konvensi spreadsheet).

**Menjalankan otomatisasi**

```bash
php artisan serve
# terminal lain:
php artisan dusk --filter=LoginTest
php artisan dusk --filter=Pbi32ScheduleReminderTest
php artisan dusk --filter=Pbi33ProgressReminderTest
php artisan dusk --filter=Pbi34EskalasiTest
```

Pastikan **Google Chrome** + **ChromeDriver** aktif, `APP_URL` di `.env` sama dengan URL server (mis. `http://127.0.0.1:8000`). Error `ERR_CONNECTION_REFUSED` berarti server Laravel tidak berjalan.
